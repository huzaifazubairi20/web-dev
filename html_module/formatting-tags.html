Formatting Tags

Following are the formatting tags used in html

Bold and Strong

BOLD :

Where we use bold tag the words there become bold like IT IS BOLD

STRONG

Where we use strong tag the words there become strong in text like IT IS STRONG

ITALIC

In this tag, the text is a bit tilted like It is italic

HIGHLIGHT

In this tag, the text is highlighted with yellow color like it is highlighted

DELETED

In this tag the text is shown cutted out like it is deleted

SUPER AND SUB SCRIPT

by using these tags words are gone under or above the lines examples : H2O , E = mc2
